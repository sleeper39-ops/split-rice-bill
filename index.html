Token คือเครดิตที่ใช้ตอนกดปุ่ม "คัดลอกสรุปส่ง LINE ทีเดียว", "คัดลอก", "ส่ง LINE", "ทวงเงิน" หรือ "สรุปเป็นรูปภาพ" — หักครั้งละ 1 Token ต่อการกด 1 ครั้ง การตั้งบิล เพิ่มเพื่อน กดจ่ายแล้ว/ยังไม่จ่าย และดูสรุปยอด ไม่ใช้ Token

❓ คำถามที่พบบ่อย
ปุ่ม "📷 AI สแกนใบเสร็จ" ใช้งานยังไง?
ใช้สำหรับถ่ายรูปหรือเลือกภาพใบเสร็จรับเงิน (อยู่ที่หัวการ์ดร้านที่ 1) เพื่อให้ AI (Google Gemini) ช่วยอ่านชื่อร้าน, เปอร์เซ็นต์ VAT และยอดเงินรวมทั้งหมด เข้าสู่บิลร้านให้อัตโนมัติทันที ไม่ต้องพิมพ์เองให้เสียเวลา

วิธีเปิดใช้งานฟรี 100% (วันละ 1,500 รูป):
1. สมัครขอรับ Gemini API Key ฟรีที่ Google AI Studio
2. นำรหัส Key มากรอกในช่อง "ตั้งค่า Gemini API Key" ด้านบน แล้วกดบันทึก
3. กดปุ่ม "📷 AI สแกนใบเสร็จ" ที่ร้านที่ 1 แล้วถ่ายรูปหรือเลือกภาพใบเสร็จเพื่อเริ่มใช้งานได้ทันที
Gemini API Key ปลอดภัยไหม ข้อมูลรั่วไหลหรือไม่?
ปลอดภัย 100% ครับ รหัส API Key ของคุณจะถูกบันทึกไว้ในเครื่องของคุณเองเท่านั้น (localStorage) ไม่มีการส่งไปเก็บไว้ที่เซิร์ฟเวอร์ใดๆ และรูปภาพใบเสร็จจะถูกส่งตรงไปยัง Google Gemini ผ่านการเข้ารหัส HTTPS ที่ปลอดภัย
Token หมดแล้วทำยังไง?
แตะไอคอน Token มุมขวาบน หรือแท็บ "เติม Token" ด้านล่าง เพื่อรับฟรีประจำวันหรือเลือกแพ็กเกจเติม
ข้อมูลบิลเก็บไว้ที่ไหน?
เก็บในเครื่องของคุณเอง (localStorage) และซิงก์ขึ้นเซิร์ฟเวอร์อัตโนมัติ (ผูกกับเครื่อง/เบราว์เซอร์นี้) ถ้าล้างแคชหรือเปลี่ยนเบราว์เซอร์ ข้อมูลบนเครื่องจะหาย แต่จะดึงกลับมาได้ถ้าเข้าจากเบราว์เซอร์เดิม
แอปนี้เชื่อมกับ LINE ยังไง?
ใช้ "ส่ง LINE" เพื่อเปิดแชทพร้อมข้อความสรุปให้ทันที และสามารถเข้าแอปนี้ผ่าน Rich Menu บน LINE Official Account ได้
ทวงเงินคนที่ยังไม่จ่ายยังไง?
ในแท็บ "สรุปยอด" กดปุ่ม "จ่ายแล้ว/ยังไม่จ่าย" ใต้ชื่อแต่ละคนเพื่ออัปเดตสถานะ แล้วกดปุ่ม "🔔 ทวงเงิน" เพื่อเปิดรายชื่อคนที่ยังไม่จ่าย กด "ส่ง LINE" ทีละคน หรือกด "ส่งทวงทีละคนอัตโนมัติ" ให้ระบบเปิดแชท LINE พร้อมข้อความทวงให้ทีละคนอัตโนมัติ (ใช้ 1 Token ต่อคน)
แก๊งเพื่อนกับประวัติทริปคืออะไร?
ในแท็บ "หารบิล" กด "บันทึก" หลังตั้งชื่อแก๊ง เพื่อเซฟรายชื่อเพื่อนกลุ่มปัจจุบันไว้ใช้ซ้ำ ครั้งต่อไปกดชื่อแก๊งก็ขึ้นรายชื่อให้ทันทีไม่ต้องพิมพ์ใหม่ (กด ✕ แล้วกดยืนยันเพื่อลบแก๊ง) ส่วนแท็บ "ประวัติ" จะเก็บสรุปยอดทุกครั้งที่กด "สร้างสรุปยอด" ไว้ให้ดูย้อนหลัง และกด "โหลดเพื่อนกลุ่มนี้" เพื่อดึงรายชื่อเพื่อนจากทริปนั้นกลับมาใช้ได้เลย
สร้างรูปสรุปยอดไปแชร์ IG/LINE ได้ไหม?
กดปุ่ม "🖼️ สรุปเป็นรูป" ในแท็บ "สรุปยอด" ระบบจะสร้างภาพสรุปยอดสวยๆ ให้ทันที กด "บันทึกรูป" เพื่อเซฟลงเครื่อง แล้วนำไปแชร์ต่อใน LINE หรือ IG Story ได้เลย (บนมือถือบางรุ่นกด "แชร์รูป" ส่งตรงได้เลยโดยไม่ต้องเซฟก่อน)
การคิด VAT % ทำงานยังไง?
คุณสามารถกรอกเปอร์เซ็นต์ VAT (เช่น 7) ในแต่ละร้านได้ (เริ่มต้นจะเว้นว่างไว้คือไม่มี VAT) เมื่อกรอกแล้ว ระบบจะคำนวณบวก VAT เข้ากับยอดบิลร้านและบิลแยกทั้งหมด พร้อมแสดงป้ายกำกับ (รวม VAT 7%) ควบคู่ไปกับจำนวนเงินทุกจุด รวมถึงในข้อความสรุปและรูปภาพแชร์
